# 🦊 Universal-MD-Clipper

[![Firefox Add-on](https://img.shields.io/badge/Firefox-Extension-orange?logo=firefox-browser)]()
[![Manifest V3](https://img.shields.io/badge/Manifest-V3-blue)]()
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)]()

**Универсальный клиппер статей в Markdown для Firefox.** 

Мгновенно сохраняйте любые веб-статьи, документацию и заметки в чистый формат Markdown с метаданными, таблицами и сохранением оригинальных ссылок на изображения. Идеально подходит для создания базы знаний в **[Obsidian](https://obsidian.md/)**, Logseq или любом другом Markdown-редакторе.

---

## ✨ Возможности

- 🧹 **Чистый Markdown:** Использует мощный движок [Turndown](https://github.com/mixmark-io/turndown) с поддержкой [GFM (GitHub Flavored Markdown)](https://github.com/turndown-plugin-gfm) для идеальной конвертации таблиц, списков задач и блоков кода.
- 🏷️ **Метаданные (Frontmatter):** Автоматически извлекает заголовок, URL, дату и автора, формируя YAML-блок, готовый к использованию в Obsidian.
- 🖼️ **Умные изображения:** Сохраняет оригинальные ссылки на изображения (или позволяет настроить их загрузку), чтобы ваша заметка не осталась без визуального контекста.
- 🔒 **Приватность и безопасность:** Работает локально в вашем браузере. Расширение запрашивает доступ только к активной вкладке и использует стандартный API загрузок Firefox. Никакие данные не отправляются на сторонние серверы.
- ⚡ **Легковесность:** Написан на чистом JavaScript (Manifest V3), без тяжелых зависимостей.

## 📥 Установка

### Вариант 1: Временная установка (для тестирования)
1. Скачайте архив с последней версией из раздела [Releases](https://github.com/ak2020k/Universal-MD-Clipper/releases) или клонируйте репозиторий.
2. Откройте Firefox и перейдите по адресу `about:debugging#/runtime/this-firefox`.
3. Нажмите кнопку **"Загрузить временное дополнение"** (Load Temporary Add-on).
4. Выберите файл `manifest.json` из папки с расширением.

## 🚀 Как пользоваться

1. Откройте любую статью или страницу, которую хотите сохранить.
2. Нажмите на иконку **Universal-MD-Clipper** на панели инструментов Firefox.
3. В появившемся окне проверьте название файла и настройки (при необходимости).
4. Нажмите кнопку **"Скачать в Markdown"**.
5. Файл `.md` будет автоматически сохранен в вашу папку загрузок, готовый для переноса в Obsidian!

## 🛠 Технологии

- **Manifest V3** – современный стандарт расширений Firefox.
- **[Turndown](https://github.com/mixmark-io/turndown)** + **[turndown-plugin-gfm](https://github.com/mixmark-io/turndown-plugin-gfm)** – надежная конвертация HTML в Markdown.
- Vanilla JavaScript, HTML, CSS – никаких тяжелых фреймворков, максимальная скорость работы.

## 🔒 Разрешения (Permissions)

Расширение запрашивает минимально необходимые права:
- `activeTab`: Для чтения содержимого только той вкладки, где вы нажали на иконку расширения.
- `downloads`: Для автоматического сохранения `.md` файла на ваш компьютер.
- `scripting`: Для внедрения скрипта очистки контента на странице.
- `<all_urls>`: Требуется для работы `scripting` на любых сайтах, с которых вы хотите сделать вырезку.
